# 兩人大富翁 / ふたりの大富豪すごろく

英雄聯盟主題的大富翁，最多 4 人（真人 2～4 人，空位由電腦補）。中文／日文介面。可以多支手機連線，也可以同一支手機輪流。

**玩：** https://therealzijin.github.io/lol-monopoly/
iPhone 建議用 Safari「分享 → 加入主畫面」，從圖示打開就沒有網址列。

## 遊戲內容
- **棋盤是召喚峽谷小地圖**：
  - 格子一圈＝上路和下路，中路斜穿、河道流過。
  - 藍方和紅方的主堡、防禦塔，巴龍和小龍巢穴，野區樹林。
- **角色**：可選任何英雄與造型。
  - 3D 模型會自動做成 Q 版手辦比例：四肢短粗、頭大、臉稍微童顏化。
  - 電腦玩家隨機抽英雄。
- **峽谷主題格子**：泉水（起點）、峽谷事件、商店、回城、陣亡（泉水等復活）、巨龍祭壇、圖奇偷家。
- **峽谷事件卡**：巴龍 Buff（租金 +50%）、擊殺賞金、打野 Gank、河道蟹、預示者撞塔……
- **防滾雪球機制**：
  - 最後一名收租減半、落後補助、劫富濟貧、房市崩跌
  - 地產稅與維護費
  - 拍賣或賣回銀行
  - 最後三回合衝刺、回合上限結算與終局獎項
- **電腦賣地**：地產超過免維護數量、又領先或缺錢時，會拿不成套的地出來拍賣（沒人出價就賣回銀行）；已經 7 塊以上只買能湊成套的地。
- **英雄語音**：收租時大笑、繳錢時陣亡台詞；擲骰、買地、升級、遇到其他英雄時偶爾隨機說一句（全體至少間隔 25 秒）。中文介面＝英文原音、日文介面＝日配。
- **3D／2D**：3D 棋盤（陰影、動畫、骰子物理），也可切換 2D 棋盤。

## 多支手機連線（最多 4 人）
一人開房、其他人輸入房號（PeerJS，星狀：來賓只連房主，房主轉發給其他人）。
- **房主**：負責規則與電腦玩家。
- **斷線**：心跳偵測；來賓斷線時先由電腦代打，用同一個名字重新加入就能接回座位。
- **同步**：每次擲骰、每走一格都推送完整狀態。
- **來賓的操作**：拍賣出價等，以 `{type:'act'}` 傳給房主處理。
- **音效**：音效事件隨狀態一起同步，兩支手機會一起響。

## 檔案
| 檔案 | 內容 |
|---|---|
| `index.html` | 頁面、樣式、Three.js 載入 |
| `game.js` | 規則、卡片、NPC、拍賣、連線、音效與語音 |
| `champs.js` | 英雄／造型選擇（Riot Data Dragon） |
| `view3d.js` | Three.js 3D 峽谷棋盤、Q 版化、動畫、鏡頭 |
| `view2d.js` | 2D 備用棋盤 |
| `tools/` | 語音抽取腳本 |

本機預覽：`python3 -m http.server 8765` 後開 http://localhost:8765 。修改 js 後要把 `index.html` 裡的 `?v=` 版本號換掉，手機才會載到新版。
